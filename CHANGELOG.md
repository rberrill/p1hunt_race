# Changelog

All notable changes to P1 Hunt Race are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Versions run from 0.1.0 toward 1.0.0, the first public release. The version is logged to the browser console.

## [0.1.0] - Unreleased

A fresh build. The earlier race prototype was never released; nothing here comes from it.

### Added
- The project scaffold: working notes, rules, the verify / UAT / release workflows, hooks and the Node self-test. No app yet.
- The race engine (`js/engine.js`, `js/config.js`): a live simulated race from the entrant list, the seed and the duration, identical on every device. Race time runs in fixed ticks of 1/60 s; the track has 2 to 3 turns per 10 s of duration with short and long straights, laid out from the seed; every car runs the same rules, building to a top speed down each straight, braking at the very end of it to the corner's speed, holding that speed to the apex and accelerating from the apex out, with seeded speed checkpoints along each straight and a seeded corner factor at each turn. Corners differ: each has a seeded sharpness, from a long fast sweeper to a short slow hairpin, and the road bends to match. Every car crosses the line, so every place has a real time. CSV import with the `name,spots` template, `-1`, `-2` suffixes for repeated names on display, CSV and JSON exports. A seed's case doesn't matter (`k7mx-4qzd` runs the same race as `K7MX-4QZD`).
- The page (`index.html`, `css/app.css`, `js/app/`): three full-screen phases in a loop. **Control:** the entrant list typed one per line or imported from a CSV (the template downloads from the page), the starting grid readable on stream, the seed with New and a Locked / Unlocked badge, the duration slider (10 to 120 s), and Start race, which says what to fix when the list is too short or too long; Clear asks first. **Race:** a perspective road drawn in code that rolls off into the distance at a vanishing point, cars seen from behind (black tyres, low pods, an engine cover with the top of the helmet showing, a two-element rear wing; each in one of twelve colors, with a second color per dozen entrants so a big field reads as distinct liveries), three start lights (the tower and the names on the cars arrive together a moment after lights out, once the field has left the line), the elapsed time in the header with the seed small beside the mark, a broadcast-style timing tower over the left of the road (as many places as fit, the top three large and the rest small, each with the car's color, the name and the gap to the leader, refreshed every second or so; a car that changes place slides its row to the new slot, growing or shrinking as it crosses the top three, with a green or red flash for a place gained or lost), names directly over the cars (the leading three always, the rest where a name has room, never piled over one another), and Pause / Play and Reset in a bar under the road; Pause, or a tap on the road, pauses the race and shows the controls large: Play, Reset race and Start over, which goes back to Control with the list and the seed kept; a hidden tab pauses the race, which resumes from the same moment. **Winner:** the winner's name large (the plain name, without the suffix a repeated name carries elsewhere), the full finish order with times, CSV and JSON export, Copy result where the browser has a clipboard, Re-run this race (the identical result) and Start over (the list kept, a new seed).
- Session restore: the list, seed and duration are saved as you edit; a reload asks Resume or Start over, and says when the last race was recorded under another version of the app.
- Settings in the link: a tunable set in the link shows as a "Tuned link" chip on every screen and is written into the exports, so a tweaked link can't pose as a stock race; unknown settings are ignored and out-of-range ones clamped.
- Reduced motion (the system setting, or `?reducedMotion=1`): the race is computed at once and the finish order fills in from last to first without motion; the result is the same.
- Layouts for a phone (up to 760 px wide), a mid-size window and a desktop; every control is at least 44 px and the bottom bars clear the phone's home indicator.
- `?selftest=1` runs the engine's self-tests in the browser and shows the version, the pass count and the reference-race fingerprint.
